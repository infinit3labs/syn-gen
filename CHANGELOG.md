# Changelog

All notable user-visible changes to syntab are documented here.

The project follows Semantic Versioning. The current package version is
declared in `pyproject.toml`; release tags use the `v<version>` form.

## [Unreleased]

### Added

- Spec compatibility policy and validation/migration guidance.
- Atomic publication and progress reporting for streamed CLI generation.

## [0.1.0] - 2026-09-02

### Added

- Spec-driven tabular and relational data generation with CSV, JSON, JSONL,
  Parquet, and SQL output.
- Profiling, disclosure controls, quality/diagnostic reports, conformance
  checks, dependency discovery, and reproducible profiling controls.
- Business-rule DSL, custom generators, conditional generation, and
  referential-integrity support.
